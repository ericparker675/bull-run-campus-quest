# Bull Run Campus Quest

Help me build an AI-powered app using Claude.

Build me a webapp that works like a Minecraft map in game. The goal of the app is to start somewhere on the USF campus, and as you walk around the campus, that map expands and shows landmarks on the map. The point of is it is to encourage exploration of the USF campus and point out new places you've never seen. The landmarks are supposed to be the major USF buildings such as the Library, ISA, ENG, MSC, etc. The app should be able to know your location.
